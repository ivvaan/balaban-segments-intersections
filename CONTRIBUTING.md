# Contributing

Thank you for your interest in this project!

## How to submit a pull request

1. Fork the repository on GitHub.
2. Create a new branch for your changes.
3. Make your changes and commit them.
4. Open a pull request from your branch to the `master` branch of this repository.

## How to cancel (close) a pull request

If you opened a pull request by mistake or no longer want it to be merged, you can close it at any time:

1. Navigate to the **Pull requests** tab of the repository on GitHub.
2. Open the pull request you want to cancel.
3. Scroll to the bottom of the pull request page.
4. Click the **Close pull request** button.

The pull request will be closed and no changes will be merged. You can reopen it later if needed.

## Reporting issues

Please use the [GitHub issue tracker](https://github.com/ivvaan/balaban-segments-intersections/issues) to report bugs or ask questions.
